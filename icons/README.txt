Put your icon PNGs in this folder (the app works without them; browsers just show a default icon).
  icon-192.png        192x192   normal icon
  icon-512.png        512x512   normal icon
  maskable-192.png    192x192   maskable (keep the logo inside the centre 80%)
  maskable-512.png    512x512   maskable
  shortcut-add-96.png 96x96     home-screen shortcut icon
Same file names = nothing else to change. Different names = edit manifest.json, index.html and the OPTIONAL list in sw.js.
